# Java Object-Oriented Programming (OOP) Project

This repository contains the practical coursework and project implementation for the **Java Object-Oriented Programming** course at Universiteti Metropolitan Tirana.

---

## 📂 Project Structure

The project follows a standard Java package-based structure:

```text
java-oop-shytllari/
│
├── bin/                 # Compiled bytecode files (.class)
├── src/                 # Source code directory
│   └── university/      # Main package containing OOP classes
│       ├── course.java          # Course domain model (credits, semester, tracking)
│       ├── professor.java       # Professor domain model (department, specialization)
│       ├── student.java         # Student domain model (GPA, enrolment tracking)
│       └── universityapp.java   # Main executable application demonstrating runtime logic
│
└── .gitignore           # Git ignore file for compiled binaries and workspace configs
